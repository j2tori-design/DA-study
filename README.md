# DA-study

pandas로 데이터 분석의 전 과정을 따라가며 정리한 학습 노트입니다. → [데이터분석_with_파이썬.ipynb](데이터분석_with_파이썬.ipynb)

| 장 | 다룬 내용 |
|---|---|
| 1. 데이터 분석에 대하여 | CSV 인코딩 확인·변경, 데이터프레임 읽기·저장 |
| 2. 데이터 수집하기 | JSON·XML 다루기, 공공 API 호출, 웹 스크래핑 |
| 3. 데이터 정제하기 | 불필요한 행·열 삭제, 중복 탐지, `groupby`, 누락값·잘못된 값 처리 |
| 4. 데이터 요약하기 | 기술통계, 분위수, 도수분포·히스토그램 |
| 5. 데이터 시각화 | matplotlib 기본 그래프 |
